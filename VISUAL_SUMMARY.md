## 🔄 Data Flow Architecture

### RoleSkillMapping Data Flow
```
Browser Component
       │
       ├──→ Mount Hook
       │    └──→ API: GET /admin/categories
       │        └──→ Response: [Category Objects]
       │            └──→ State: categories[]
       │                └──→ Calculate Stats
       │                └──→ Set first category
       │                    └──→ API: GET /admin/frameworks
       │
       ├──→ User: Select Category
       │    └──→ API: GET /admin/frameworks?category=X
       │        └──→ Response: [Framework Objects]
       │            └──→ State: frameworks[]
       │
       └──→ Render UI
            ├─ Stats Display
            ├─ Category Buttons
            ├─ Frameworks Table
            └─ Mapped Roles
```

### GapAnalysisConfig Data Flow
```
Browser Component
       │
       ├──→ Mount Hook
       │    ├─→ Load Config: localStorage.getItem()
       │    │   └─→ Parse & Set State
       │    │   └─→ Set Default if not found
       │    │
       │    ├─→ API: GET /recommendations/stats
       │    │   └─→ Response: Stats Object
       │    │       └─→ State: stats
       │    │
       │    └─→ Load History: localStorage.getItem()
       │        └─→ Parse & Set State
       │
       ├──→ User: Adjust Settings
       │    └─→ handleConfigChange()
       │        └─→ Update State
       │            └─→ Mark: unsaved
       │
       ├──→ User: Click Save
       │    └─→ saveConfiguration()
       │        ├─→ localStorage.setItem(config)
       │        ├─→ Add to History
       │        ├─→ Limit to 10 entries
       │        ├─→ localStorage.setItem(history)
       │        └─→ Show Success Notification
       │
       └──→ Render UI
            ├─ Stats Display
            ├─ Threshold Sliders
            ├─ Feature Toggles
            ├─ Configuration History
            └─ Action Buttons
```
